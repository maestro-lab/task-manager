# Документация REST API

## 1. Общая информация

API используется для взаимодействия frontend-приложения React с серверной частью Node.js и базой данных PostgreSQL.

**Базовый адрес:** `http://localhost:5000`

Все запросы используют формат JSON, если передают данные.

## 2. Доступные методы

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/tasks` | Получение всех задач |
| POST | `/api/tasks` | Создание задачи |
| PATCH | `/api/tasks/:id` | Изменение статуса задачи |
| DELETE | `/api/tasks/:id` | Удаление задачи |

## 3. Получение списка задач

**GET `/api/tasks`**

Возвращает список всех задач из базы данных.

Пример ответа:

```json
[
  {
    "id": 1,
    "title": "Изучить React",
    "completed": false,
    "created_at": "2026-11-12T10:00:00.000Z"
  }
]
```

## 4. Создание задачи

**POST `/api/tasks`**

Тело запроса:

```json
{
  "title": "Изучить PostgreSQL"
}
```

При успешном создании возвращается HTTP 201 и созданная запись.

Если название пустое, сервер возвращает HTTP 400.

## 5. Изменение статуса задачи

**PATCH `/api/tasks/:id`**

Изменяет статус выполнения задачи с указанным идентификатором.

Пример запроса:

```http
PATCH /api/tasks/1
```

Тело запроса не требуется.

При успешном изменении возвращается обновлённая задача.

Если задача не найдена, возвращается HTTP 404.

## 6. Удаление задачи

**DELETE `/api/tasks/:id`**

Удаляет задачу по её идентификатору.

Пример запроса:

```http
DELETE /api/tasks/1
```

При успешном удалении возвращается:

```json
{
  "message": "Задача удалена"
}
```

## 7. Обработка ошибок

| HTTP-код | Описание |
|---|---|
| 200 | Запрос выполнен успешно |
| 201 | Запись успешно создана |
| 400 | Некорректные данные |
| 404 | Задача не найдена |
| 500 | Внутренняя ошибка сервера |

## 8. Тестирование

Для автоматического тестирования API используется Supertest и встроенный Node.js Test Runner.

Запуск тестов:

```bash
npm test
```

В проекте реализовано пять автоматических тестов: получение списка, создание задачи, проверка пустого названия, изменение статуса и удаление задачи.
