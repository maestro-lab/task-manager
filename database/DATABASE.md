# Документация базы данных Task Manager

## 1. Общая информация

Для хранения данных приложения Task Manager используется система управления базами данных PostgreSQL.

База данных называется `task_manager`.

Она предназначена для хранения задач пользователя.

## 2. Структура базы данных

В базе данных используется таблица `tasks`.

| Поле | Тип данных | Ограничения | Назначение |
|---|---|---|---|
| id | SERIAL | PRIMARY KEY | Уникальный идентификатор |
| title | VARCHAR(255) | NOT NULL | Название задачи |
| completed | BOOLEAN | NOT NULL, DEFAULT FALSE | Статус выполнения |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | Дата создания |

## 3. Первичный ключ

Поле `id` является первичным ключом (PRIMARY KEY).

Оно обеспечивает уникальность каждой записи и позволяет обращаться к конкретной задаче.

## 4. Ограничения целостности

В таблице используются следующие ограничения:

- PRIMARY KEY — уникальная идентификация записи.
- NOT NULL — обязательное заполнение названия задачи.
- DEFAULT FALSE — новая задача по умолчанию считается невыполненной.
- DEFAULT CURRENT_TIMESTAMP — дата создания устанавливается автоматически.

## 5. Индекс

Для поля `created_at` предусмотрен индекс `idx_tasks_created_at`.

Он предназначен для ускорения запросов, в которых используется дата создания задачи.

## 6. Операции с данными

В приложении реализованы основные операции:

- SELECT — получение списка задач.
- INSERT — добавление новой задачи.
- UPDATE — изменение статуса выполнения.
- DELETE — удаление задачи.

Операции выполняются серверной частью приложения через PostgreSQL.

## 7. Связь с приложением

Frontend отправляет HTTP-запросы серверу Express.

Backend обрабатывает запросы и выполняет SQL-команды в PostgreSQL.

Полученные данные возвращаются frontend-приложению в формате JSON.

## 8. Безопасность данных

Для работы с базой данных используются параметризованные SQL-запросы.

Настройки подключения хранятся в файле `.env`, который исключён из Git с помощью `.gitignore`.
